
# 🫒 SpendOlive

> 고정·변동 지출 관리 및 OTT 구독 공유·정산 통합 플랫폼

## 📌 프로젝트 소개

SpendOlive는 개인의 고정 지출과 변동 지출을
체계적으로 관리하고, OTT 구독 공유 및 정산을
하나의 서비스에서 이용할 수 있도록 기획한
웹 기반 통합 지출 관리 플랫폼입니다.

### 기획 배경

- 지속적으로 증가하는 구독 서비스 관리의 필요성
- 고정 지출과 변동 지출을 통합 관리하는 기능의 필요성
- OTT 공유 및 정산 과정에서 발생하는 불편함
- 직관적인 지출 분석 및 시각화의 필요성

## 🛠️ 기술 스택

- Language : Java 21, JavaScript
- Backend : Spring Boot, JdbcTemplate
- Frontend : JSP, JSTL, HTML, CSS
- Database : Oracle Database
- Build : Maven
- Version Control : Git, GitHub

## 💡 주요 서비스 기능

| 기능 | 설명 |
|---|---|
| 회원 관리 | 회원가입, 로그인, 회원정보 관리 |
| 지출 관리 | 고정·변동·OTT 지출 등록 및 관리 |
| 예산 관리 | 월별 예산 설정 및 사용 현황 확인 |
| 지출 분석 | 월별·카테고리별 소비 데이터 시각화 |
| OTT 공유 | 공유방 생성, 검색, 참여 및 초대 |
| 정산 관리 | 공유방 참여자의 정산 상태 확인 |
| 마이페이지 | 개인 정보, 계좌 및 카드 관리 |
| 관리자 | 회원 및 서비스 운영 현황 관리 |
